# Knowledge Base (The Second Brain)

This directory is an **Obsidian Vault**. It serves as the shared long-term memory for:
1.  **The User** (via Obsidian on Desktop/Mobile).
2.  **The Agents** (via reading these markdown files).

## Structure (PARA Method)
*   `00-Inbox/`: Unprocessed notes and raw dumps.
*   `10-Projects/`: Active projects with defined goals and deadlines (e.g., `c4/`).
*   `20-Areas/`: Ongoing responsibilities with no end date (e.g., `Health`, `Finance`, `Servers`).
*   `30-Resources/`: Reference materials, cheat sheets, and learning notes.
*   `40-Archives/`: Completed projects and inactive areas.

## Agent Protocol
*   **Read-Only**: Agents should primarily *read* from here to understand context.
*   **Inbox-Write**: If an Agent needs to store a new persistently useful fact, it should write a markdown file to `00-Inbox/` with a descriptive name.
